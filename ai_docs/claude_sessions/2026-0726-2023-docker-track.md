## What this session did

Added **`docker` — "Docker & Compose"**, 18 problems on the existing
`go-wasm` runner. Zero engine changes. Premise: Docker is usually taught
as CLI incantations; here the learner IMPLEMENTS the daemon's decision
procedures as pure Go over declared inputs (refs, layers, events, service
graphs) — no daemon, no socket. Per user directive, docker-compose is a
first-class arc (4 of 18 items), covering the four mechanisms behind
every `docker compose up`.

### Items (4 categories, 3 Easy / 14 Medium / 1 Hard)

- **Images & Builds**: `image-references` (Easy; docker.io/library/latest
  normalization, registry heuristic `.`/`:`/localhost, Familiar
  round-trip), `image-layers` (overlay union: upper-wins, `.wh.`
  whiteouts, opaque dirs, "rm never shrinks an image"),
  `dockerfile-eval` (layer-creating RUN/COPY/ADD vs metadata-only ops,
  ENV substitution, relative WORKDIR), `build-cache` (parent-hit AND
  text-match for RUN / content-checksum for COPY; first miss busts the
  tail; the go.mod-before-source ordering pattern), `dockerignore`
  (segment-wise glob, `**`, `!` re-include, last-match-wins),
  `entrypoint-cmd` (Easy; the full ENTRYPOINT×CMD table, shell-form
  PID-1/SIGTERM trap, `--entrypoint` dropping image CMD)
- **Running Containers**: `container-lifecycle` (Easy; created/running/
  paused/exited/removed state machine with docker-CLI-flavored errors),
  `restart-policies` (no/always/unless-stopped/on-failure:N + manual-stop
  override; 100ms-doubling backoff capped 60s), `port-publishing`
  (`[hostIP:]hostPort[-range]:containerPort[-range][/proto]` parsing,
  range 1:1 expansion, EXPOSE-publishes-nothing, `-P`),
  `volumes-mounts` (bind vs named vs anonymous sniffing, copy-on-first-use
  only for empty volumes — never binds (the node_modules war story),
  longest-segment-prefix shadowing), `healthchecks`
  (starting→healthy⇄unhealthy; start-period shield, consecutive-failure
  retries, streak reset), `resource-limits` (binary-multiplier
  ParseBytes, float-free `--cpus`→CFS quota/period, OOM boundary;
  cgroup v2 renames in explanation)
- **Networking & Distribution**: `bridge-networks` (embedded DNS at
  127.0.0.11: per-network scoping, aliases, default bridge resolves
  nothing, shared-network IP answer), `manifest-platforms` (containerd
  matcher: arm64 v8≡"", arm variant fallback v8→v7→v6 down only,
  first-listed tie-break, digest pinning)
- **Compose**: `compose-interpolation` (`${VAR:-…}` vs `${VAR-…}`,
  `:?` errors, `$$`, shell-env-over-.env precedence; `.env` vs
  `env_file:` confusion as the war story), `compose-merge` (`-f` chains:
  scalars replace, maps merge per-key, sequences append+dedupe; why you
  can't remove a port in an override; `!reset` mention),
  `compose-dependencies` (Hard; depends_on conditions incl.
  service_healthy-requires-healthcheck validation, Kahn's-algorithm
  startup waves sorted within wave, deterministic cycle naming),
  `compose-networks` (v2 dash container names vs underscore network
  names, shared-network reachability, ports-irrelevant
  container-to-container, expose-doesn't-publish)
